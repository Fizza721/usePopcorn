# 🍿 usePopcorn

usePopcorn is a movie search and watchlist application built with React.js as a practice project to strengthen my front-end development skills.

Users can search for their favorite movies, explore movie details, rate movies, and maintain a personal watched-movies list.

### 🔗 Links

- **Live Demo:** [View Project](https://usepopcorn-site.netlify.app/)
- **GitHub Repository:** [View Source Code](https://github.com/Fizza721/usePopcorn)

### Features

- Search movies by title.
- View movie details.
- Rate movies.
- Add movies to a watched list.
- Remove movies from the watched list.
- View watched-movie statistics.

### Technologies

- React.js
- JavaScript (ES6+)
- CSS
- OMDb API

### Purpose

This project helped me practice React Hooks, state management, API integration, component composition, conditional rendering, and handling user interactions.
